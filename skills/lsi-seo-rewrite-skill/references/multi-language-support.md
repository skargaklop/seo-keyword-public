# Multi-Language Support for LSI SEO Rewrite

## Overview

This document provides language-specific guidance for SEO content rewriting across English (en), Russian (ru), and Ukrainian (uk). It covers anti-AI pattern detection, LSI dictionary sources, and search engine optimization considerations for each language.

---

## Language-Specific Anti-AI Patterns

### English Patterns (Tier 1-3)

**Tier 1 - Always Remove:**
- **Correlative constructions:** "It's not X, it's Y", "Not only X, but also Y"
- **Rhetorical flourishes:** "In today's fast-paced world", "In this ever-changing landscape"
- **Staccato phrasing:** "Here's the thing. The reality is this."
- **Vocabulary:** delve, leverage, robust, seamless, game-changer, testament to, unlock, harness, empower, elevate, foster, facilitate
- **Formatting:** Em dashes (>1 per 1000 words), bold overuse, emoji in headers
- **Openers/Closers:** "In today's...", "In conclusion...", "To summarize...", "Ultimately...", "Moving forward..."

**Tier 2 - Flag in Clusters (2+ in paragraph):**
- harness, navigate, foster, elevate, empower, facilitate
- streamline, bolster, cultivate, illuminate
- ecosystem, myriad, plethora, encompass
- innovative, impactful, transformative, cutting-edge

**Tier 3 - Flag at High Density (>3% of words):**
- significant, effective, dynamic, scalable
- compelling, unprecedented, exceptional, remarkable
- comprehensive, strategic, optimized, enhanced

### Russian Patterns (Русские паттерны)

**Tier 1 - Всегда удалять:**
- **Канцеляризмы:** "осуществлять деятельность", "реализовывать мероприятия", "проводить работу"
- **Штампы:** "в современных реалиях", "в todays realities", "на сегодняшний день", "в настоящее время"
- **Риторические фразы:** "Стоит отметить", "Важно подчеркнуть", "Необходимо упомянуть", "Следует сказать"
- **Лже-активность:** "ведущая роль отводится", "уделяется особое внимание", "проводится комплексная работа"
- **Иностранные заимствования (неуместные):** "драйвер", "сторить", "пилить", "скилл", "бекграунд"
- **Закрытия:** "подводя итог", "в заключение", "в завершение", "делая выводы"

**Tier 2 - Флаг при кластерах (2+ в абзаце):**
- продвигать, развивать, улучшать, повышать
- оптимизировать, модернизировать, трансформировать
- инновационный, передовой, перспективный
- эффективный, результативный, успешный

**Tier 3 - Флаг при высокой плотности (>3% слов):**
- значимый, важный, существенный
- качественный, профессиональный, надежный
- современный, актуальный, сегодняшний

### Ukrainian Patterns (Українські паттерни)

**Tier 1 - Завжди видаляти:**
- **Канцеляризми:** "здійснювати діяльність", "реалізовувати заходи", "проводити роботу"
- **Штампи:** "в сучасних реаліях", "на сьогоднішній день", "в даний час"
- **Риторичні фрази:** "Варто зазначити", "Важливо підкреслити", "Необхідно згадати", "Слід сказати"
- **Лже-активність:** "ведуча роль відводиться", "зосереджується особлива увага", "проводиться комплексна робота"
- **Закриття:** "підсумовуючи", "у завершенні", "роблячи висновки"

**Tier 2 - Прапорець у кластерах (2+ в абзаці):**
- просувати, розвивати, покращувати, підвищувати
- оптимізувати, модернізувати, трансформувати
- інноваційний, перспективний, передовий
- ефективний, результативний, успішний

**Tier 3 - Прапорець при високій щільності (>3% слів):**
- значущий, важливий, суттєвий
- якісний, професійний, надійний
- сучасний, актуальний, нинішній

## Language-Specific SEO Considerations

### English (Google Focus)

**Search Engine:** Google (global)

**Key Considerations:**
- Title tags: 50-60 characters
- Meta descriptions: 150-160 characters
- H1 optimization: Primary keyword naturally integrated
- Content length: 300+ words for products, 500+ for categories
- Readability: Flesch-Kincaid Grade Level 8-10
- Schema markup: Product, Review, FAQPage

**Google-Specific Factors:**
- E-A-T (Expertise, Authoritativeness, Trustworthiness)
- Mobile-first indexing
- Core Web Vitals (LCP, FID, CLS)
- Passage ranking for long-tail queries
- BERT for natural language understanding

### Russian (Yandex + Google)

**Search Engines:** Yandex (primary) + Google (secondary)

**Yandex-Specific Considerations:**
- **Т-spelling support:** Accommodate common typos and keyboard layout errors
- **Morphology:** Russian word forms are extensively analyzed (stemming)
- **Geo-factors:** Regional ranking is crucial (Kyiv vs. regional queries)
- **Commercial factors:** Explicitly evaluated (company details, contact info, policies)
- **Behavioral factors:** User engagement metrics heavily weighted
- **User signals:** Click-through rate, time on site, return visits

**Yandex Metadata:**
- Title: 60-70 characters (slightly more tolerant than Google)
- Description: 160-180 characters
- Keywords tag: Still used by Yandex (unlike Google)
- OG/Yandex meta tags for social sharing

**Russian-Specific Challenges:**
- Case sensitivity in some contexts
- Cyrillic URL support
- Synonym handling (rich Russian morphology)
- Duplicate content across .ru, .com, .ua versions

**Yandex Metrica (Analytics):**
- Alternative to Google Analytics
- Provides heatmaps and session recording
- Important for Russian market optimization

### Ukrainian (Google Ukraine + Local)

**Search Engines:** Google Ukraine (primary) + Yandex (limited presence since 2022)

**Google Ukraine-Specific Considerations:**
- **Region-specific ranking:** Kyiv-based servers/hosting favored
- **Local citations:** Ukrainian business directories (Ukr.net, Bigmir)
- **Language detection:** Proper lang="uk" attribute critical
- **Mobile optimization:** High mobile usage in Ukraine

**Ukrainian Language Features:**
- **Alphabet:** Cyrillic with specific letters (ґ, є, і, ї)
- **Grammar:** Rich morphology (7 cases, verb aspects)
- **Vocabulary:** Distinct from Russian despite similarities
- **Loanwords:** Increasing adoption of English technical terms

**Cultural Considerations:**
- Holiday calendar (Independence Day, Christmas by Julian/Gregorian)
- Payment methods (PrivatBank, monobank preferences)
- Delivery networks (Нова Пошта, Укрпошта, Justin)
- Social media platforms (Facebook/Instagram dominance over VK)

**Post-2022 Context:**
- Yandex withdrawal from Ukrainian market
- Increased reliance on Google services
- Growing importance of local Ukrainian platforms
- Language purity movements (de-russification of terminology)

## Implementation Guide

### Language Detection

**Detection Methods:**
1. **Explicit user input:** Language parameter provided
2. **Character set detection:** Cyrillic vs Latin script
3. **Language detection tools:** Python `langdetect`, `polyglot`
4. **Content analysis:** Keyword list matching

**Detection Code Example:**
```python
from langdetect import detect, DetectorFactory

DetectorFactory.seed = 0  # For consistent results

def detect_language(text):
    try:
        lang = detect(text)
        return lang if lang in ['en', 'ru', 'uk'] else 'en'  # Default fallback
    except:
        return 'en'  # Fallback for very short text
```

### Pattern Application

**English Content Processing:**
1. Apply Tier 1-3 patterns from `references/anti-ai-patterns.md`
2. Use general e-commerce LSI terms
3. Optimize for Google SEO standards

**Russian Content Processing:**
1. Apply Russian-specific Tier 1-3 patterns
2. Integrate LSI from `packaging-lsi-dictionary.md`
3. Optimize for Yandex (primary) + Google
4. Apply morphology-aware keyword matching

**Ukrainian Content Processing:**
1. Apply Ukrainian-specific Tier 1-3 patterns
2. Use translated/ adapted Russian LSI terms
3. Optimize for Google Ukraine
4. Apply local commercial factors

### Character Limits per Language

**Title Tags:**
- English: 50-60 characters (Google)
- Russian: 60-70 characters (Yandex tolerant)
- Ukrainian: 50-60 characters (Google)

**Meta Descriptions:**
- English: 150-160 characters
- Russian: 160-180 characters
- Ukrainian: 150-160 characters

**Content Length Targets:**
- English: 300+ words (product), 500+ words (category)
- Russian: 400+ words (product), 600+ words (category) - Russian SEO prefers slightly longer content
- Ukrainian: 300+ words (product), 500+ words (category)

**H1 Length:**
- All languages: 60-70 characters maximum
- All languages: One primary keyword natural integration

### LSI Integration by Language

**English LSI Integration:**
1. Extract from Google SERP (PAA, Related Searches)
2. Apply TF-IDF from top-10 competitors (Ahrefs/Semrush)
3. Target density: 8-12 LSI terms per 1,000 words
4. Placement: H1 > Lead > H2/H3 > Body > FAQ

**Russian LSI Integration:**
1. Extract from Yandex SERP ("Также ищут")
2. Apply from packaging-lsi-dictionary.md
3. Target density: 10-15 terms per 1,000 words (Yandex prefers slightly higher semantic density)
4. Include morphological variations (word forms)

**Ukrainian LSI Integration:**
1. Extract from Google Ukraine SERP
2. Adapt from Russian dictionary with localization
3. Target density: 8-12 terms per 1,000 words
4. Include Ukrainian-specific commercial terms

## Hreflang Implementation

For multi-language sites, implement proper hreflang tags:

```html
<link rel="alternate" hreflang="en" href="https://example.com/en/product" />
<link rel="alternate" hreflang="ru" href="https://example.com/ru/product" />
<link rel="alternate" hreflang="uk" href="https://example.com/uk/product" />
<link rel="alternate" hreflang="x-default" href="https://example.com/product" />
```

**Important:**
- Use ISO 639-1 language codes (en, ru, uk)
- Include x-default for international audiences
- Ensure bidirectional linking between language versions
- Verify with Google Search Console International Targeting report

## Best Practices Summary

1. **Never auto-translate:** Always have native speaker review
2. **Respect cultural differences:** Humor, holidays, values differ
3. **Localize, don't translate:** Adapt examples, currencies, measurements
4. **Test in target search engines:** Verify Yandex for Russian, Google Ukraine for Ukrainian
5. **Monitor local competitors:** Each language has different competitive landscape
6. **Stay updated:** Search engine algorithms differ by region
7. **Consider political context:** Especially for Ukrainian market post-2022
