# Product Page Template

SEO-optimized product page structure with LSI integration, FAB framework, and anti-AI pattern compliance.

## H1 Formula

**Structure:** `[Brand] + [Product Name] + [Specific Descriptors]`

**Character Limit:** 60-70 characters maximum

### Variant Handling Rules

**Separate Pages (Different URLs):**
- Include descriptor in H1 when each product variant has its own page
- Examples: "Мужская куртка The North Face Nuptse", "Женская куртка The North Face Nuptse"
- Required when: Gender, color, or size variants have separate URLs

**Unified Pages (Selector-Based):**
- Keep H1 universal when variants are selected via UI (no URL change)
- Example: "Смартфон Apple iPhone 15 Pro" (NOT "Смартфон Apple iPhone 15 Pro черный")
- Required when: Colors/sizes chosen via dropdown or visual selector
- Prevents semantic narrowing and duplicate content issues

### H1 Examples

| Product Type | H1 Example | Notes |
|--------------|------------|-------|
| Running shoes | Asics Gel-Kayano 29 Mens Running Shoes | Gender-specific for separate page |
| Smartphone | Samsung Galaxy S24 Ultra 5G 256GB | Storage variant as separate page |
| Packaging | Коробка картонная Т11 500x350x300 мм | Dimensions as specific descriptor |
| Generic | Curad Waterproof Bandages Assorted Sizes | Selector-based (no color in H1) |

## Lead Paragraph Structure

**Length:** 100-150 words

**Formula:**
```
[Product Name] delivers [primary benefit] for [target use case].
[Integration of 2-3 LSI terms]. [Value proposition without filler].
```

### Lead Template

```markdown
[Product Name] delivers [primary benefit] for [target use case].
Designed with [LSI term 1] and [LSI term 2], this [product category]
provides [specific value proposition]. The [key feature] ensures [outcome],
making it ideal for [specific application/scenario].
```

### Lead Requirements

1. **Hook Sentence:** First sentence must name product + primary benefit
2. **LSI Integration:** 2-3 LSI terms naturally woven in (no keyword stuffing)
3. **No Filler:** Avoid "In today's world," "Cutting-edge," "Revolutionary"
4. **Specificity:** Concrete details over vague claims
5. **Benefit-Forward:** Feature → What it does → User outcome

### Lead Example (Packaging Product)

```markdown
Коробка картонная Т11 обеспечивает надежную защиту грузов при транспортировке.
Изготовленная из трехслойного гофрокартона с маркировкой Т11, эта транспортная тара
выдерживает нагрузку до 15 кг и подходит для автоматической линии упаковки.
Идеальное решение для интернет-магазинов и складской логистики.
```

**LSI Terms Used:** трехслойный гофрокартон, транспортная тара, нагрузка

## Body Content Template

**Minimum Length:** 300+ words

### Structure Outline

```markdown
## Product Overview (100-150 words)
[Product Name] delivers [primary benefit] for [target use case].
[LSI term 1] integration provides [specific advantage], while
[LSI term 2] ensures [outcome].

## Key Features (with LSI Integration)
- **[Feature 1]:** [Technical LSI term] + specification + use case
- **[Feature 2]:** [Material/process LSI term] + what it enables
- **[Feature 3]:** [Application LSI term] + user benefit
- **[Feature 4]:** [Performance metric LSI term] + value delivered

## Why Choose [Product] (FAB Framework)
- **Feature:** [Feature description with LSI]
- **Attribute:** [Why it matters + metric/spec]
- **Benefit:** [User outcome + behavioral modifier]

## Technical Specifications
| Specification | Value | Unit |
|--------------|-------|------|
| [Spec 1] | [Value 1] | [Unit] |
| [Spec 2] | [Value 2] | [Unit] |

## Common Questions (FAQ from PAA)
**Q: [PAA question 1]?**
A: [Answer with LSI term integration, 50-80 words]

**Q: [PAA question 2]?**
A: [Answer with LSI term integration, 50-80 words]
```

### FAB Framework Application

**Features (Что это):**
- Technical facts with LSI terms
- Materials, dimensions, certifications
- Specifications and capabilities

**Attributes (Почему это важно):**
- Metrics and performance data
- Industry standards (ГОСТ, ISO)
- Comparative advantages

**Benefits (Что дает клиенту):**
- User outcomes and experiences
- Problem solutions
- Behavioral results (saves time, reduces cost, improves safety)

### FAB Examples by Category

**Packaging (Carton Box):**
- **Feature:** Трехслойный гофрокартон марки Т11
- **Attribute:** Выдерживает сжатие до 15 кг (BCT rating)
- **Benefit:** Ваши товары доходят intact, снижение возвратов на 40%

**Electronics (Headphones):**
- **Feature:** Активное шумоподавление с ANC-чипом
- **Attribute:** Блокирует 95% внешнего шума (40 dB)
- **Benefit:** Полное погружение в музыку, работа в шумном офисе без отвлечений

**Clothing (Jacket):**
- **Feature:** Мембрана Gore-Tex 3L с проклеенными швами
- **Attribute:** Водостойкость 20,000 мм водяного столба
- **Benefit:** Остаетесь сухим в ливень, никаких промоканий

## Meta Tags Generation

### Title Tag Formula

**Length:** 50-60 characters

**Structure:** `[Primary Keyword] - [Secondary Keyword] | [Brand]`

**Examples:**
- "Картонные коробки Т11 оптом купить | Упаковка-Про"
- "Asics Gel-Kayano 29 Mens Running Shoes | RunFit"
- "Samsung Galaxy S24 Ultra 5G Review | TechZone"

**Rules:**
1. Primary keyword near the beginning
2. No keyword repetition (avoid "Running Shoes - Best Running Shoes")
3. Include brand or domain at end
4. No clickbait (avoid "BEST MUST BUY!!!")
5. Unique per page (no duplicates across catalog)

### Meta Description Formula

**Length:** 150-160 characters

**Structure:** `[Action verb] + [Product name] + [Key benefit] + [LSI term] + [CTA]`

**Examples:**
- "Заказать картонные коробки Т11 с доставкой по Киеву. Прочная тара для переезда и интернет-магазинов. ГОСТ 9142. Купить оптом от производителя."
- "Shop Asics Gel-Kayano 29 with free shipping. Max cushioning for overpronators. Duomax support system. Buy now with 30-day returns."

**Template:**
```
[Action: Order/Buy/Shop] [product name] with [key benefit].
[LSI-rich phrase about use case]. [CTA phrase].
```

**CTA Examples:**
- "Buy now with free shipping"
- "Заказать с доставкой сегодня"
- "Shop online with 30-day returns"
- "Купить оптом от производителя"

## Product Page LSI Categories

### 1. Technical Specifications LSI
- Materials, dimensions, measurements
- Industry standards (ГОСТ, ISO, CE)
- Performance metrics (load capacity, durability)
- Process terminology (manufacturing method)

### 2. Use Case LSI
- Application scenarios (for relocation, for warehouse)
- Target audience descriptions (e-commerce, logistics, production)
- Problem-solution language (protects fragile cargo, prevents damage)
- Context-specific terms (cold storage, heavy-duty)

### 3. Comparison LSI
- Versus alternatives (better than corrugated, lighter than wood)
- Category differentiators (waterproof vs water-resistant)
- Competitive advantages (reinforced bottom, double-wall)
- Selection criteria language (how to choose, what to look for)

### 4. Commercial Modifiers LSI
- Transaction signals (buy, order, price, wholesale, delivery)
- Availability (in stock, ready to ship, from manufacturer)
- Geographic (Ukraine, Kiev, delivery across Ukraine)
- B2B signals (bulk orders, custom sizes, wholesale pricing)

## Quality Checklist

### H1 Verification
- [ ] H1 contains brand + product name + specific descriptors
- [ ] Character count 60-70 or less
- [ ] For selector-based pages: NO color/size variants in H1
- [ ] For separate pages: variant descriptor included
- [ ] H1 matches URL slug (hyphenated, lowercase)
- [ ] No special characters or emojis in H1

### Lead Paragraph Verification
- [ ] Length 100-150 words
- [ ] First sentence names product + primary benefit
- [ ] 2-3 LSI terms naturally integrated
- [ ] No AI filler phrases ("cutting-edge," "revolutionary," "game-changer")
- [ ] No Tier 1 anti-AI patterns (delve, leverage, robust, seamless)
- [ ] Specifics present (numbers, measurements, concrete details)
- [ ] Benefit explicitly stated (not just features)

### Body Content Verification
- [ ] Total word count 300+ words
- [ ] At least 4 feature bullet points with LSI
- [ ] FAB section includes all three elements (Feature/Attribute/Benefit)
- [ ] Technical specs table present with units
- [ ] At least 2 FAQ questions from PAA
- [ ] FAQ answers include LSI terms
- [ ] No keyword stuffing (density 8-12 LSI terms per 1000 words)
- [ ] Primary keyword in first 100 words
- [ ] Secondary keywords in H2/H3 headings

### Meta Tags Verification
- [ ] Title tag 50-60 characters
- [ ] Title includes primary keyword near start
- [ ] No keyword repetition in title
- [ ] Meta description 150-160 characters
- [ ] Meta description includes CTA
- [ ] Meta description includes 1-2 LSI terms
- [ ] Both title and description unique across site

### Anti-AI Pattern Verification
- [ ] No Tier 1 patterns: "It's not X, it's Y" constructions
- [ ] No Tier 1 vocabulary: delve, leverage, robust, game-changer, testament to
- [ ] No em dash overuse (max 1 per 1000 words)
- [ ] No bold overuse (max 5% of words)
- [ ] No forbidden openers: "In today's fast-paced world"
- [ ] No forbidden closers: "In conclusion," "To summarize"
- [ ] No emoji in headers or body text
- [ ] Tier 2 words checked: No clusters of 2+ in one paragraph
- [ ] Tier 3 density: No single word >3% of total word count

### E-A-T and Commercial Factors
- [ ] Contact information visible
- [ ] Return/shipping policy linked
- [ ] Reviews or UGC section present
- [ ] High-quality product images (alt text with LSI)
- [ ] Price and availability clear
- [ ] Trust signals (SSL certificates, badges if applicable)

## Common Anti-Patterns to Avoid

### H1 Mistakes
❌ "The Ultimate Running Shoe for Serious Athletes" (Too generic)
❌ "iPhone 15 Pro - Black - 256GB - Unlocked" (Selector-based with variants)
❌ "BEST Waterproof Hiking Boots EVER!" (Clickbait, all caps)

✅ "Asics Gel-Kayano 29 Mens Running Shoes"
✅ "Apple iPhone 15 Pro 256GB"
✅ "Merrell Moab 3 Waterproof Hiking Boots"

### Lead Paragraph Mistakes
❌ "In today's fast-paced world, you need a shoe that can keep up with your lifestyle..." (Forbidden opener)
❌ "This revolutionary game-changer will transform your running experience..." (Tier 1 vocabulary)
❌ "The Nike Pegasus is a shoe that is designed for running and is good for runners." (Redundant, thin)

✅ "Nike Air Zoom Pegasus 40 delivers responsive cushioning for daily training. With React foam and Zoom Air units, this neutral running shoe provides energy return for miles 1 through 10. Ideal for runners seeking versatility from 5K to marathon distance."

### Meta Description Mistakes
❌ "Click here for the best running shoes at the best prices. Shop now!" (Too vague, no LSI)
❌ "Nike Air Zoom Pegasus 40 Mens Running Shoes Nike Running Shoes Mens" (Keyword stuffing)
❌ "Buy running shoes" (Too short, no benefit)

✅ "Shop Nike Air Zoom Pegasus 40 with free shipping. Responsive cushioning for daily training. Neutral support for 5K to marathon. Buy now with 30-day returns."

## Implementation Notes

1. **SERP Analysis First:** Before writing, extract PAA questions and "Related Searches" for LSI
2. **Competitor Scan:** Check top 5 competitors for missing LSI terms
3. **Unique Value:** Identify what makes this product different and lead with it
4. **Localize for Language:** Apply appropriate patterns for en/ru/uk (see multi-language-support.md)
5. **Mobile Preview:** Test on mobile SERP preview tool before finalizing
6. **Iterate Based on Data:** Monitor CTR and adjust meta tags monthly
